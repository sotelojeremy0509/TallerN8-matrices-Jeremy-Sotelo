# Taller 8 - Matrices y Conjuntos en Python

Repositorio con los dos ejercicios del Taller 8 de Lógica de Programación de la Universidad de La Salle.

## Requisitos

- Python 3.10 o superior.
## Archivos

- `ejercicio1_matrices.py`: programa de análisis de ventas.
- `ejercicio2_conjuntos.py`: programa de análisis de estudiantes inscritos en cursos.


**Ejercicio 1:**
- Consulta los resultados del análisis de ventas.
- Ingresa el número del vendedor y de la semana para modificar una venta.
- Introduce el nuevo valor para actualizar los resultados.

**Ejercicio 2:**
- Consulta los estudiantes registrados y las operaciones entre cursos.
- Escribe el nombre del nuevo estudiante.
- Selecciona el curso A o B para agregarlo.
- Consulta los resultados actualizados.
